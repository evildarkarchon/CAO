## What to build

Concentrate work diagnostic and failure retention and publication with AssetRun, coordinated with the executor observation sink. Preparing observations and completed evidence remain available through interruptions, and observers cannot cause duplicate delivery or change Run Outcome.

## Acceptance criteria

- [ ] Give Run Diagnostics and Run Failures one coordinated recording/publication path, including observations already retained during Preparing. Neither AssetRun nor the executor sink independently appends a second copy.
- [ ] Retain evidence before calling downstream observers. Advance publication bookkeeping independently of observer success so a throwing callback cannot append or deliver the same observation again.
- [ ] Remove ApplicationRunWork's diagnostic/failure publication cursors and remaining normal-return observation reconciliation; callers do not orchestrate a separate recording protocol.
- [ ] Preserve preflight failure and Archive Collision observations before mutation and work diagnostics at their established point before Archive Finalization. Retention survives interruption even when the normal reporting point is not reached.
- [ ] Through production recording beneath the Run Executor, verify Preparing observations followed by work observations and terminal completion have the expected order and multiplicity, with no lost or duplicated evidence.
- [ ] Exercise throwing progress and diagnostic observers after evidence is recorded. Retain attempts and failures, avoid publication replay, and keep ObserverFailed diagnostics informational without changing terminal outcome precedence.
- [ ] Exercise observers that request cancellation and then throw, including diagnostic-triggered cancellation before finalization. Honor cancellation at established checkpoints, preserve evidence, and always perform Safety Cleanup.
- [ ] Retain existing public lifecycle and dispatch regression tests without duplicating scheduling scenarios in the new work tests.
- [ ] Validate the changed behavior through the project's profile-triplet workflow. If blocked, diagnose and report the blocker; alternate-generator checks do not replace that validation.
- [ ] Document non-obvious ordering and lifetime constraints and added or substantially rewritten methods. Preserve accurate existing comments and update the knowledge graph after implementation changes.
- [ ] Preserve ADR-0001 and public Run Request, Run Handle, result, observation, scheduling, and lifetime contracts. Keep terminal classification and mandatory Safety Cleanup with the Run Executor.
