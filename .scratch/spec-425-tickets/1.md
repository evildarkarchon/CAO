## What to build

Prefactor internal composition so deterministic tests can supply controlled operation adapters beneath the existing synchronous Run Executor while exercising the production AssetRun recording path. Application dependency preparation remains in ApplicationRunWork. This establishes the shared behavioral seam needed for the recording changes in the parent spec.

## Acceptance criteria

- [ ] Production and tests invoke the same AssetRun orchestration and recording implementation beneath the synchronous Run Executor; controlled adapters perform operations and return outcomes rather than reproducing recording rules.
- [ ] Keep the composition change at the existing operation-adapter seam, with no generic recording framework, speculative adapter abstraction, or public test-only API.
- [ ] Demonstrate through that shared path that a completed committed attempt remains in terminal evidence exactly once after a later orchestration failure, and Safety Cleanup still runs. Cover Archive extraction followed by interrupted discovery and Asset work followed by later failure where practical through existing seams.
- [ ] Assert terminal evidence, mutation summaries, cleanup, and observable behavior rather than private containers or helper calls. Adapt relevant existing handwritten-work tests without removing unrelated executor contract coverage.
- [ ] Keep existing behavior green during this prefactor; retain public Optimization Run lifecycle and dispatch tests as regression coverage.
- [ ] Validate the changed behavior through the project's profile-triplet workflow. If blocked, diagnose and report the blocker; alternate-generator checks do not replace that validation.
- [ ] Document non-obvious ordering and lifetime constraints and added or substantially rewritten methods. Preserve accurate existing comments and update the knowledge graph after implementation changes.
- [ ] Preserve ADR-0001 and public Run Request, Run Handle, result, observation, scheduling, and lifetime contracts. Keep terminal classification and mandatory Safety Cleanup with the Run Executor.
