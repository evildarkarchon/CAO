# Recover interrupted Archive Transactions before planning

CAO will make each Archive Transaction crash-recoverable through an owned per-Mod workspace at `.cao-transactions/<transaction-id>`. A versioned, human-readable, framed append-only write-ahead journal is the sole rollback truth: every intent is durably flushed before its filesystem mutation, an absent commit record always rolls back to the pre-transaction Mod state, and a durable commit record makes published output authoritative so recovery only completes deferred deletion and workspace cleanup. Intentionally retained extraction backups remain final Assets; rollback-only copies of replaced archives and delete-source loose Assets are removed after commit.

Asset Work Plan Execution will expose one production execution operation whose implementation identifies the selected Mods, acquires kernel-held sibling lock files in deterministic path order, performs Archive Recovery, plans Asset Work Items, executes them, and releases the locks. The lock file also contains a durable workspace-bootstrap record so a crash between creating the reserved root and flushing its internal manifest does not produce an unowned directory. Runtime rollback and restart recovery use the same journal replay implementation; recovery is uninterruptible, fail-closed, path-confined, and blocks the whole execution on an in-scope failure.

Dry Run acquires the same locks and validates recovery state without mutation. If rollback or committed cleanup is required, it reports that recovery is required and stops before Asset Work Items are planned. Legacy unjournaled workspaces, unknown or inconsistent journals, multiple incomplete transactions for one Mod, path escapes, identity changes, and filesystems that cannot provide the required durable flush and same-volume atomic-move semantics all block execution without mutation.

Workspaces are kept inside their owning Mod so they cannot become Mods during several-Mod selection; the reserved root is excluded from archive packing, archive and loose Asset discovery, Mod Asset Metadata discovery, and empty-directory cleanup. The generic planner remains ignorant of workspace naming. This replaces the shallow planner workaround and both in-memory archive journals while preserving the deep BSA Optimizer interface, the three-operation execution interface from ADR-0002, one extraction transaction per source archive, and one packing transaction per Mod.
