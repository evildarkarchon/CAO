# Port CAO to Rust and Slint

Qt 5.15 is end-of-life, the vcpkg/CMake/Qt build is heavy, and bethutil's void archive mutators expose no mutation facts, so CAO is ported to a Rust Cargo workspace with a Slint GUI that keeps the same native engines (DirectXTex with GPU BC7, nifly, `hkxcmd.exe`) and reads and writes Archives through the `ba2` crate. The C++ tree was not maintained alongside the port, and the port is complete: the C++ tree was deleted (#515), and the differential harness that checked the port against it was removed once it had served its purpose. C++ behaviour is history, not a constraint: where code notes what C++ did, that explains where a behaviour came from, and any of it may change on its own merits. The original spec is #476.
