# Port CAO to Rust and Slint

Qt 5.15 is end-of-life, the vcpkg/CMake/Qt build is heavy, and bethutil's void archive mutators expose no mutation facts, so CAO is ported to a Rust Cargo workspace with a Slint GUI that keeps the same native engines (DirectXTex with GPU BC7, nifly, `hkxcmd.exe`) and reads and writes Archives through the `ba2` crate. The C++ tree is not maintained alongside the port: its CLI survives only as a differential parity oracle that the Rust build is compared against, and once that corpus passes all C++ is deleted. Output must be equivalent to what C++ CAO produces under equivalence rules set per Asset Kind, not byte-identical, because the two builds compile the same engines differently and the port is not worth reproducing incidental bytes such as compressed archive layout. Behaviours that are clearly unintended are fixed rather than copied; each fix is on the spec's explicit deviation list, pinned by a Rust-only test, and kept out of the parity corpus so a fix is never reported as a regression. The spec is #476.
