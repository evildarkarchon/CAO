# Fork branding specimen

> **THROWAWAY PROTOTYPE:** this is decision-support material, not production port code or final artwork. Keep the selected naming and asset contract in `VERDICT.md`, then delete or replace this directory.

Question: what final product name and visual identity should distinguish the Rust/Slint fork while fitting the resolved Workbench and producing unambiguous executable, release-artifact, icon, and Windows-metadata names?

The specimen places three deliberately different identity systems over the same compact Workbench slice:

- **A — Asset Kiln:** warm, tactile, and refinement-led.
- **B — Meldframe:** cool, modular, and system-led.
- **C — Tracetide:** calm, directional, and traceability-led. **Selected by the maintainer.**

The specimen now opens on C. A and B remain only as comparison evidence for the Wayfinder decision; they are rejected as the fork identity and must not be treated as implementation options.

Run from the repository root:

```powershell
cargo run --locked --manifest-path .\prototypes\slint-branding-specimen\Cargo.toml
```

Use the fixed bottom prototype bar or the Left/Right arrow keys to switch identity candidates. Use the theme control to compare Light and Dark. The controls are read-only decision aids; no configuration or filesystem mutation occurs.

Candidate collision checks are preliminary product research, not trademark clearance. Recheck the selected name before repository/domain registration and before release.
